# Contributing to SmartFlowSocial Publisher

Node.js 20+ and pnpm 10 (see `packageManager` in `package.json`).

```bash
pnpm install
pnpm validate
pnpm test
```

## Pull requests

- Branch from `main` and keep the change focused.
- Use a semantic PR title (`feat`, `fix`, `docs`, `refactor`, `test`, `chore`).
- Run `pnpm validate` and `pnpm test` before opening the pull request.
- Update the README or `docs/` when behavior, configuration, or the API changes.

## Code of conduct

This project follows the [SmartFlowSocial Code of Conduct](CODE_OF_CONDUCT.md). Report unacceptable behavior to **conduct@smartflow.social**.
